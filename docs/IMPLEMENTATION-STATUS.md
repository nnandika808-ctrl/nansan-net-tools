## GitHub hosting package

[aaPanel guide](AAPANEL-HOSTING.md) covers Apache/Nginx public document root, PHP 8.4 CLI/FPM, production secrets, permissions, Redis, worker, scheduler, backup/restore, acceptance and rollback. The Checks workflow builds a new no-dev production ZIP with a commit/file inventory and SHA256, then extracts that actual ZIP into a fresh directory for migration, idempotent seeding, optimized boot and HTTP/private-path smoke. Successful runs publish a private 14-day artifact with build/smoke reports. Use the latest successful run for the exact desired commit; this does not merge the feature branch or deploy the server.

Added `nansan:hosting-check --production --runtime`: it fails on missing assets/extensions, unsafe configuration, missing schema/admin, failed DB/Redis/cache, stale/future background heartbeats and missing recent verified backup; it never prints secret values. It checks prerequisites only, not external TLS/Turnstile validity, off-host recovery, capacity, legal approval or RouterOS behavior. Queue defaults now use a 900-second retry window above the 600-second backup/610-second worker timeout. `doctor --queue` no longer counts synchronous dispatch as worker evidence. Six regression cases cover these failures.
