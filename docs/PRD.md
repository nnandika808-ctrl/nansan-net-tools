# NANSAN NET Tools — scope baseline

Owner: NANSAN NET. Product: a completely free MikroTik script-generator platform. Default Indonesian; English and dark/light/system preferences. Public beta is the intended release, not a claim of current production readiness. Logo is deferred by the owner; use the text brand until supplied.

## Evidence-led generator scope

Only G01 Static Routing, G02 Queue QoS, G03 PCC, G04 PCC Starlink and G05 Static Routing Games are in scope. See reference/GENERATOR-INVENTORY.md for sources and observations. Do not introduce other generators. Initial authenticated audit covers five default form inventories, sixteen scenarios and a structural mobile check. Exhaustive validation and option combinations remain incomplete.

G01/G02 depend on .rsc data; G05 needs verifiable port/protocol data. Exclusive datasets cannot be redistributed on the assumption that Premium access permits it. The owner reports permission to follow the behavior; exact fixture and dataset redistribution scope is still unestablished. Independently implement reviewed logic. No generic configuration may substitute for unaudited reference behavior.

## Required experience

- Public: landing, five-tool catalog, categories, synonyms, instant search, documentation and editable information/legal pages.
- Identity: unique username/password, optional remember-me, Turnstile on deployment, safe sessions, no required email or OAuth, one-time recovery codes. Public registration always creates User; Admin is created by Artisan.
- Workspace: overview, favorites, script history, presets, announcements/read state, profile/avatar, preferences, device sessions, feedback and verified account deletion with a 30-day grace period.
- Admin: overview, user activation, tool metadata, CMS articles/pages/announcements, media, feedback state/replies, settings/maintenance, audit records and real monitoring.
- Generator: consistent module contract, observed forms, server validation/normalization, explicit RouterOS handling, separately retained output steps, highlighting, copy, .rsc download, history/presets and versioned regression evidence. Backend authority cannot be bypassed by frontend or metadata edits.
- Operations: MySQL + Redis, worker + scheduler, protected staging, backups with independent retention and restore tests, Nginx/PHP-FPM behind Cloudflare Tunnel, CI and rollback.

## Release acceptance

Publication needs reviewed implementation, sufficient authorized fixtures, regression results, relevant RouterOS lab evidence, and no critical unresolved gap. Exact text and full semantic effects are distinct; a parameter projection does not prove either. No router is configured automatically. Public generators require login. Unready generators remain unavailable.

Production requires staging acceptance, verified backups/restore and monitoring, deployment credentials/secrets configured, owner-reviewed legal drafts, correct domains/TLS and explicit owner approval. No progress percentages are used. The authoritative completion report is IMPLEMENTATION-STATUS.md.
